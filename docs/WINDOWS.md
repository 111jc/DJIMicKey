# DJI Mic Key 1.0.0

轻量 Windows 工具：检测 DJI Mic Mini 接收器、显示麦克风输入电平，并将发射器连接键转换为自定义键盘快捷键。

## 主界面

主界面按参考 HTML 实现：左侧是设备状态、电平条和输入峰值趋势；右侧是连接键示意、键帽组合、录制按钮及启动设置。底栏左侧分色显示监听和映射状态，右侧显示本次运行的触发次数及最近触发时间。计数表示 Windows 接受了快捷键发送，不代表输入法确认识别。

字体沿用 HTML 的系统字体规则：英文使用 Segoe UI，中文显式回退到 Microsoft YaHei UI，电平数值和日志使用 Courier New。缩放兼容默认开启，包含系统字体放大及逐显示器 DPI 调整，不再提供单独开关。窄窗口会改为单列并允许滚动。

窗口使用四周对称的透明阴影层，便于区分白色背景上的边界；阴影不截获点击，只在尺寸变化时重新生成，无后台动画计时。主窗口与诊断窗口均禁用最大化及标题栏双击最大化，主界面仅保留最小化和关闭按钮。收到配对键的按下事件时，设备示意灯闪亮约 300 毫秒；暂停映射时仍提供检测反馈。该反馈沿用现有 Volume Up 检测范围。

刷新、诊断、连接、电源及窗口控制图标使用可缩放线条绘制。保留原生 Windows Forms，不依赖浏览器或第三方 UI 框架。

## 运行与设置

运行环境为 Windows 10/11 x64 和 .NET Framework 4.8。双击 DJIMicKey.exe，无需安装 AutoHotkey、驱动或 Node.js。

1. 通过 USB 连接接收器，确认设备显示已连接。
2. 点击“启动测试”，对着麦克风说话查看电平和趋势；“停止测试”会释放音频采集。读取失败时，将鼠标移到数值、测试按钮或趋势图上查看原因。
3. 点击“开始录制”，按下并松开目标按键或组合键，再点击“应用并保存”。保留左右 Ctrl / Alt / Shift / Win 的区别；Esc、10 秒超时、离开窗口或“取消录制”可取消。
4. 设置保存成功后新组合才生效。保存失败会保留原映射及录制草稿，允许重试。
5. 在输入法中设置完全相同的语音快捷键。在文字输入框中，短按连接键开始语音，再短按一次结束。

默认快捷键为“左 Ctrl + 左 Alt + F9”。此前单独模拟右 Ctrl 在本机未成功，组合快捷键已由用户实测确认。软件只发送快捷键，语音开始、结束状态由输入法控制。

设置保存在 %LOCALAPPDATA%\DJIMicKey\settings.ini。移动 EXE 不影响快捷键设置。旧配置也会自动启用缩放兼容；配置损坏时会暂停映射并提示重新配置。

## 关闭与开机启动

点击右上角 × 后选择“完全退出”或“最小化到托盘”。托盘模式保留映射、停止麦克风电平采集，双击托盘图标恢复窗口。关闭选择框或按 Esc 会取消。托盘菜单和 Stop.cmd 可以直接退出。

“开机自动启动”写入当前用户的 HKCU\Software\Microsoft\Windows\CurrentVersion\Run，值名 DJIMicKey，命令为带引号的 EXE 绝对路径加 --autostart。登录 Windows 后在托盘运行，不主动开启电平测试。取消勾选仅删除本程序的启动项，无需管理员权限。

请先将 EXE 放在固定位置再开启启动。移动后需重新勾选以更新路径；如果 Windows 任务管理器禁用了启动项，需要在那里重新启用。

## 映射范围与设备限制

本工具按 Windows Volume Up 媒体键类型拦截。在接收器就绪、映射启用时，键盘及其他设备的“音量加”也会触发目标快捷键；映射开关悬停提示会说明这一范围。不安装输入过滤驱动，也没有按设备来源隔离。

暂停映射、断开接收器或退出程序后，音量加恢复原功能。“已连接”表示接收器 HID 和音频接口就绪，不代表能读取发射器无线配对状态；请用说话测试确认音频链路。

电源键的独立可映射信号尚未确认：隔离测试未收到事件，之后的实时采集存在物理按键来源歧义。详见 docs/POWER_BUTTON_FINDINGS.md。当前不提供独立电源键映射。

## 诊断与排查

点击“诊断”打开实时日志弹窗，可导出报告、重启按键监听。每次采集最多 60 秒，关闭弹窗会结束本次采集；主程序继续运行。只记录媒体键、Windows 多媒体命令、DJI HID 报告及运行状态，不记录普通文字或保存音频。

- 未连接：检查 USB 接收器并点击“刷新”。当前适配 VID_2CA3 / PID_4011 和活动 Wireless Mic / DJI Mic 音频接口；其他型号及蓝牙直连未保证。
- 无电平：确认发射器已开机、配对、未静音，并检查 Windows 麦克风权限或独占占用。
- 快捷键不触发：先直接用实体键盘测试同一组合，核对左右修饰键。普通权限程序不能保证向管理员窗口注入快捷键。
- Win11 设备、电平正常却仍增加音量：导出按键诊断，参见 docs/WIN11_TROUBLESHOOTING.md。当前尚未在该 Win11 实机确认原因或修复。

独立电源键观察命令：DJIMicKey.exe --power-watch report.txt 60。时间范围 15–120 秒，只记录媒体键与 DJI HID，不录音。

## 资源占用与原理

单个 EXE 约 120 KiB。电平每 80 ms 更新，设备每 3 秒复查并响应插拔；窗口隐藏或最小化时，停止电平计时器并释放 WASAPI 采集流。后台保留按键监听和设备检测，不录制文件、不上传音频、不连接网络。实际内存取决于 Windows、DPI、字体和输入法组件。

DeviceProbe 检测 HID 与 Core Audio 端点；KeyboardMapper 在独立消息线程安装 WH_KEYBOARD_LL，消费 Volume Up 的按下、松开事件。MappingGate 去除重复与抖动，松开后通过 SendInput 发送目标组合。只忽略本工具自己的注入标记，兼容观察到的大疆事件标记 0x11 / 0x91。音频包直接释放，不复制到文件。

## 源码构建与验证

Build.cmd 使用系统 C# 编译器构建，并运行 57 项基础检查。Test.cmd 额外验证缩放、真实键盘录制、保存失败重试、关闭与托盘、诊断日志；需要交互式 Windows 桌面。Test.cmd --device 增加当前接收器检查。

Release.cmd 构建便携压缩包，包含程序、使用说明、诊断说明和 MIT 许可证。正式 EXE 重建前先退出程序。报告位于 .build/reports，分发文件位于 dist。

DPI 检查包含 100%、125%、150%、175%、200% 缩放模拟、额外 35% 字体放大、窄窗口和重复 DPI 消息；真实窗口截图检查切换与缩放后的绘制。模拟不能替代所有物理混合缩放显示器的实测。

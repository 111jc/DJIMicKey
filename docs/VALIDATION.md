# v1.0.2 验证记录

2026-10-31：用户明确确认更新版已兼容其 Win11 电脑，配对键可控制微信输入法语音开始/结束，且不再弹出音量调节。此项为用户实测反馈，不是合成测试推断。

## 自动检查

73 项基础检查覆盖原生 ABI、组合键及左右修饰键、设置、录制、Raw-only 与混合输入去重、畸形 report、暂停/设备移除，以及原生 Shell DLL 的启用、停用、其他命令放行和所有者销毁保护。

Test.cmd 覆盖 100%–200% DPI、放大文字/窄窗口、无双向滚动条、边界和遮挡、反复 DPI 切换、录制/保存失败重试、关闭/托盘、诊断弹窗生命周期及实际窗口绘制反馈。报告保存在 .build/reports/。

测试注入有安全钩子消费，不向其他应用发送目标组合或自动调节系统音量。合成输入和原生决策测试不能当成真实 TX 按键。

## 硬件与限制

- 本次 Win11 语音启停与音量条抑制：用户确认 PASS。
- Win10 在旧输入链路上已有用户成功反馈；新版双通路由自动回归覆盖，但不能冒充新的 Win10 实体按键验收。
- 接收器适配限实际 2CA3:4011，不保证其他产品、蓝牙或所有 Win11 应用环境。
- Shell 拦截覆盖同桌面可到达的未处理命令，不是按物理设备隔离；可能影响其他来源的音量增加。
- 设备不在线时 --device 检查应报告未就绪，不能伪造通过。
- 没有验证电源键独立映射、手机、长期录音或所有物理混合 DPI 显示器。
- 本工具不改变 USB 驱动、固件、系统音量值，不保存或上传声音。
